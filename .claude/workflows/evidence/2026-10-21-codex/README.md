## 实测中发现并修复的问题

1. 设计评审误要求尚未实现的代码通过测试：改为只审方案覆盖和一致性，不把已知失败基线当成设计缺陷。
2. verifier 无法核实修复前失败与测试未修改：由主进程先采集 baseline_checks 和 initial_snapshot，后续显式交接当前指纹及验收输出。

保留失败记录，不把前两次中断描述为成功。第三次完成上述全部闭环。
