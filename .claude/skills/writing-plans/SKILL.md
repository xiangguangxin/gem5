# Writing Plans

## 实施计划 Skill

目标：

将设计转换为可执行任务。

一个好的计划包括：

-   修改文件
-   修改目的
-   实现步骤
-   测试方法

示例：

Task:

实现 Eth_Transmit

修改：

Eth.cpp

内容：

-   检查Controller状态
-   检查Buffer
-   更新Tx队列

验证：

Eth_Transmit_Test
